Вопросы

Коротко о главном

Нужны ли права администратора?

Нет. Установщик ставит Flortrap в вашу папку. Данные и Roblox лежат отдельно, в C:\FRoblox.

Это официальный лаунчер Roblox?

Нет. Flortrap сделан независимо и не связан с Roblox Corporation. Используйте настройки на свой риск: Roblox может менять правила и игнорировать часть флагов.

Безопасны ли моды?

Моды состоят только из данных: флагов и ресурсов. Исполняемые файлы и скрипты Flortrap не распаковывает, а пути для замены ограничены папками контента Roblox.

Что делать, если столкнулся с проблемой?

Если у вас есть проблема или вопрос, вы можете обратиться в наш Discord Server.

Установка

  • Скачайте Flortrap-Setup.exe с главной страницы или из релизов на GitHub.
  • Запустите установщик. Права администратора не нужны.
  • Выберите папку, ярлыки (рабочий стол, меню «Пуск»), закрепление на панели задач и запуск после установки.
  • Когда круг дойдёт до 100% и появится белая галочка, установка закончена.

Если запустить установщик ещё раз, он спросит, переустановить ли Flortrap. Удалить программу можно в «Параметры → Приложения». Данные и сам Roblox лежат отдельно, в папке C:\FRoblox, и при удалении программы остаются.

Первый запуск

На вкладке Home нажмите Launch Roblox. Flortrap скачает или обновит Roblox, применит ваши настройки и запустит игру. Вкладка Roblox с историей игр появляется после первого запуска.

КнопкаЧто делает
VerifyПроверяет файлы игры.
RepairИсправляет частые проблемы.
FolderОткрывает папку данных.

Настройки

Настройки разделены на пять вкладок. Все опции выключены, пока вы сами их не включите. Изменения применяются при следующем запуске Roblox из Flortrap.

ВкладкаЧто внутри
GraphicsЛимит и разблокировка FPS, качество, настройки движка: текстуры, детали игры, MFAA, FXAA, DirectX, Vulkan или OpenGL, память.
SpeedПриоритет процесса Roblox, очистка кэша, запуск вместе с Windows.
CustomizeСвой курсор, шрифт, текстуры и фон окна, включая GIF.
FlagsСвои FastFlags.
GeneralМультизапуск, поиск сервера по региону, сворачивание в трей, статус Discord, экспорт и импорт настроек.

FastFlags

FastFlag это внутренний параметр Roblox. Flortrap записывает выбранные флаги в файл ClientAppSettings.json перед каждым запуском. Roblox принимает только флаги из своего белого списка и молча игнорирует остальные, поэтому часть флагов может ничего не менять.

  • Откройте Settings → Flags и включите главный переключатель. По умолчанию он выключен.
  • Подтвердите предупреждение о неизвестных флагах.
  • Добавьте имя и значение флага. Значение может быть true, false, числом или текстом.
  • Удалённые и выключенные флаги убираются из файла при следующем запуске.
{
  "DFIntTaskSchedulerTargetFps": 240,
  "FIntRenderShadowIntensity": 0
}
Используйте только флаги, в которых уверены. Flortrap не может проверить, что принимает Roblox, и Roblox может изменить правила в любой момент.

Моды

Мод это папка с файлом mod.json. Он может задать флаги и заменить файлы Roblox, например курсор. Код в модах не запускается.

Установка мода

Откройте вкладку Mods и нажмите Download. Мод включится сам. Переключатель на карточке включает и выключает его, Remove удаляет мод и возвращает оригинальные файлы.

Свой мод

  • Нажмите Open mods folder (C:\FRoblox\Mods) и создайте папку, например my-mod. Имя папки это id мода.
  • Положите в неё mod.json, по желанию banner.png и папку files.
  • Нажмите Refresh и включите мод.
{
  "id": "my-mod",
  "name": "My Mod",
  "description": "Turns shadows off.",
  "version": "1.0.0",
  "author": "You",
  "flags": { "FIntRenderShadowIntensity": 0 },
  "files": [
    { "from": "files/ArrowCursor.png",
      "to": "content/textures/Cursors/KeyboardMouse/ArrowCursor.png" }
  ]
}
ПолеЗначение
idСтрочные буквы, цифры, дефис и подчёркивание, от 2 до 41 символа. Должен совпадать с именем папки.
name, descriptionНазвание и описание на карточке.
versionНапример 1.2.0. Более новая версия в каталоге показывает кнопку Update.
flagsОбъект с FastFlags.
filesСписок замен: from внутри мода, to внутри папки Roblox. Путь to должен начинаться с content/, PlatformContent/ или ExtraContent/.

Разрешены картинки, звуки, шрифты и простые данные. Программы и скрипты не копируются. Лимит: 500 файлов и 100 МБ на мод. Оригинальные файлы сохраняются и возвращаются при выключении мода.

Каталог на GitHub

Вкладка Mods читает mods/catalog.json из репозитория slenderhold/Flortrap. Добавьте запись со ссылкой на zip и откройте pull request.

{ "mods": [ {
  "id": "my-mod", "name": "My Mod", "version": "1.0.0",
  "description": "Turns shadows off.", "author": "You",
  "package": "https://github.com/you/my-mod/releases/download/v1.0.0/my-mod.zip",
  "banner": "https://raw.githubusercontent.com/you/my-mod/main/banner.png"
} ] }

Обновления

Flortrap проверяет последний релиз на GitHub. Если вышла новая версия, он скачивает Flortrap-Setup.exe, запускает тихую установку, закрывает старую программу и оставляет новую. Версия считается новой, если номер релиза выше номера установленной программы.
