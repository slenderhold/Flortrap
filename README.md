## 📦 **Installation**

1. Download the latest **`Flortrap-Setup.exe`** from [Releases](https://github.com/slenderhold/Flortrap/releases)
2. Run it — **no administrator rights required**
3. Launch Flortrap and click ▶ **Launch Roblox**
