✨ Features
🚀 Fast launch — starts Roblox faster than the official client
🎛 FastFlags — add, import and apply custom flags on every launch
🎨 Deep customization — fonts, cursors, skyboxes and more via built-in Store
🖥 Multi-instance — run multiple Roblox clients simultaneously
📈 Richer rendering — configurable graphics quality levels
📊 Play stats — tracks daily and weekly time in-game
🔔 Discord RPC — rich presence showing current game
🛡 No admin rights needed — installs per-user to `C:\Flortrap`
---
📦 Installation
Download the latest `Flortrap-Setup.exe` from Releases
Run it — no administrator rights required
Launch Flortrap and click ▶ Launch Roblox
---
🛠 Build from source
Requirements: .NET 8 SDK
```bash
git clone https://github.com/slenderhold/Flortrap
cd Flortrap
build-installer.bat
# Output: dist\Flortrap-Setup.exe
```
